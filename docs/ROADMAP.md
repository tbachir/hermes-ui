# Roadmap

## v0.1 — foundation and operational UI

- server-only Hermes clients
- Supabase auth guard
- narrow Next.js API routes
- status/profile/session/Kanban components
- API Server Run console
- Command Center
- workflow editor

## v0.2 — native control-plane catalog

- package namespace `@burner-io/hermes` / `@burner-io/workflow`
- skills, models, MCP, toolsets, cron, webhooks, providers, credentials, memory and plugins
- analytics, gateway, updates and logs
- safe config and redacted environment management
- read-only managed filesystem and allow-listed Git inspection
- doctor/security-audit operations
- learning/Curator, messaging, Portal and audio
- composed capabilities/models/automation/observability/developer/learning/communication/system centers
- complete `hermes-control-plane`
- dedicated App Router pages

## v0.3 — deep native workflows

- Kanban task drawer, comments, dependencies, diagnostics, mutation controls and live events
- session detail/message timeline, search, pin/archive/export/import and safe prune flows
- managed-file preview/download plus separately permissioned write/upload actions
- Git review/diff plus separately permissioned stage/commit/push/PR actions
- messaging onboarding and pairing approval workflows
- audio transcription and streaming playback
- config form editing driven by the native schema while preserving secret boundaries
- granular route-level policy callbacks beyond the initial user allow-list

## v0.4 — persisted app layer on Supabase

- Supabase schema for app-owned Hermes connection metadata
- run history/audit trail with RLS
- saved workflow documents and workflow runs
- human approval inbox
- per-user/per-organization Hermes access policies

## v0.5 — realtime and durable UX

- API Server SSE bridge for Runs
- Kanban event feed
- realtime run timeline
- AI Elements Tool/Reasoning/Checkpoint renderers
- notification surface
- resumable workflow approval inbox

## v0.6 — templates

- complete app shell and navigation preset
- multi-workspace Hermes cockpit composition
- workflow studio page
- specs / validation workflow blocks
